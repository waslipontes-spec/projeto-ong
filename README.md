
# Projeto ONG

Projeto desenvolvido para a atividade Projeto Integrador Extensionista II.

## Tecnologias utilizadas

- Vite+
- Vanilla JavaScript
- Node.js
- Express
- pnpm

## Funcionalidades

- Página inicial do projeto.
- API Express.
- Rota GET `/api/health`.
- Exibição do status da API na página inicial.
- Exibição da data e hora da resposta.

## Como executar o projeto

### 1. Instalar as dependências

```bash
pnpm install
```

### 2. Configurar o ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
API_PORT=3000
```

### 3. Iniciar a API

Em um terminal:

```bash
pnpm api
```

### 4. Iniciar o frontend

Em outro terminal:

```bash
pnpm dev
```

### 5. Acessar o projeto

Frontend: http://localhost:5173/

API: http://localhost:3000/api/health
